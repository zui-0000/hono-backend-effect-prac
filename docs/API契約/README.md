# API 契約についての判断

`schema/`（TypeSpec）で書く外部契約の**形**について決めたことを、判断ごとに 1 ファイルで残す。

「どう動くか」は [`02-architecture.md`](../02-architecture.md) に、
「これから決めること」は [`04-backlog.md`](../04-backlog.md) の
「契約を 2026 年時点の一次情報で洗い直す」にある。ここに置くのは**決着したもの**だけ。

## 決着したもの

- [エラー応答を RFC 9457 に寄せるか](エラー応答をRFC9457に寄せるか.md) — 寄せない（2026-08-14）

## まだ決まっていないもの

`04-backlog.md` の一覧から、判断が要る行だけを再掲する。決着したらここへ 1 ファイル足す。

| 領域             | 状況                                                                |
| ---------------- | ------------------------------------------------------------------- |
| ページネーション | **最優先。** 用意済みの型がページ番号方式、デファクトはカーソル方式 |
| バージョニング   | 未決（いまはパスに `v1` を持たない）                                |
| 認証方式         | 「なぜ OAuth ではなく自前のトークン発行か」が未記述                 |
| 廃止告知         | `Deprecation` / `Sunset` ヘッダ 未実装                              |
| レートリミット   | 429 + `X-RateLimit-*` 未実装                                        |
| 冪等キー         | `Idempotency-Key` 未実装                                            |

ページネーションだけ**期限がある**。`listUsers` の契約を書いた瞬間に
「変えない」判断へ固定されるため、書き始める前に決める。
